Accomplishments So Far

We have established the full C++ project architecture for the water droplet simulator. The codebase is organized into modular subsystems under src/: core (droplet mesh and data structures), sim (solver logic), forces (surface tension, adhesion, drag), surface (plane abstraction), render (OpenGL stubs), interaction (drag force field), ui (ImGui stubs), and app (application entry point), with main.cpp as the entry point. The build system is set up via CMake with vcpkg dependency management, targeting cross-platform compatibility between macOS M1 and Ubuntu 22.04. Key simulation classes — PlaneSurface, DropletTemplate, DropletFactory, and SingleDropletSolver — are defined and architecturally connected.

Preliminary Results

The project skeleton compiles and runs. The CPU-side simulation architecture is in place with clear separation between physics logic and rendering. The OpenGL renderer and ImGui UI exist as stubs, ready for graphics code to be filled in without interference from the simulation core. Parameter hooks for friction, viscosity, surface tension, contact angle, and volume correction are stubbed into the solver interface.

  • Simulation environment setup: complete
  • Basic droplet physics (surface tension, adhesion): in progress
  • Zero-gravity interactive drag: in progress
  • Vertical glass surface mode: in progress
  • Real-time refractive shading: in progress
